# Airline-reservation-system
Overview
The Airline Reservation System is a software application designed to manage flight bookings, check seat availability, and provide an interface for users (customers and administrators) to interact with airline services. This system supports key functionalities like flight search, booking, cancellation, and user management.

Features
🔍 Search flights by destination, date, and airline

📆 View available flights and seat availability

🎫 Book and cancel tickets

👤 User authentication (Admin & Customer roles)

📋 Admin panel to add/edit/delete flights

📜 Booking history for users

📊 Dashboard for admins

Technologies Used
Frontend: HTML, CSS, JavaScript

Backend: Java

Database: MySQL

Other Tools: Git, Postman (for API testing), etc.
